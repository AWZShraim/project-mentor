# Mentor Infra

Terraform for AWS resources (API hosting, Postgres/RDS, SQS, EventBridge, auth). Populated once Phase 1 infra needs are defined; see [../docs/technical_spec.md](../docs/technical_spec.md).

## Remote state

`bootstrap/` is a one-time, self-contained Terraform config (local state — it creates the very backend everything else uses, so it can't depend on it). It has already been applied and created:

- S3 bucket: `mentor-tfstate-384668480848` (versioned, encrypted, public access blocked) — region `ca-central-1`
- DynamoDB table: `mentor-tfstate-lock` — used for state locking

Every other Terraform config in this repo (once created) should point at this backend:

```hcl
terraform {
  backend "s3" {
    bucket         = "mentor-tfstate-384668480848"
    key            = "<component-name>/terraform.tfstate"  # e.g. "api/terraform.tfstate"
    region         = "ca-central-1"
    dynamodb_table = "mentor-tfstate-lock"
    encrypt        = true
  }
}
```

Don't re-run `bootstrap/` unless the state bucket/lock table need to be recreated from scratch.

## Components

- `bootstrap/` — one-time, local-state setup of the S3 bucket + DynamoDB lock table above
- `auth/` — Cognito User Pool + public app client for authentication
- `api/` — the deployed backend: a single free-tier EC2 instance (`t3.micro`) running the FastAPI app as a systemd service, plus a free-tier RDS Postgres instance. No inbound SSH — shell access is via SSM Session Manager (`aws ssm start-session --target <instance-id>`), IAM-authenticated instead of key/port-based. DB credentials are generated by Terraform and stored in SSM Parameter Store (SecureString), never committed or embedded in plaintext.

This is a deliberately simple single-instance deployment to unblock iOS integration testing — not the final architecture. Phase 4 (multi-user hardening / distributed backend) is where this becomes ECS Fargate + a proper VPC + the orchestration workers, once there's an actual distributed system to justify that complexity.

**Known gaps in `api/` to revisit before this is production-grade:**
- No TLS — the API is plain HTTP (`http://<ip>:8000`). Fine for early dev; needs a real domain + cert before real users.
- No automated redeploy — code updates currently require `ssm start-session`-ing in and manually `git pull && systemctl restart mentor-api`.
- RDS lives in the default VPC's public subnets (not publicly accessible itself, security-group-restricted to the EC2 instance, but not in a true private subnet).
