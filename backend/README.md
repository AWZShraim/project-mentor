# Mentor Backend

Python/FastAPI API service and AI orchestration workers. See [../docs/technical_spec.md](../docs/technical_spec.md) for architecture.

## Database setup (local Postgres)

Requires a local PostgreSQL server running. One-time setup of the app's role/database (as the `postgres` superuser):

```sql
CREATE ROLE mentor WITH LOGIN PASSWORD 'mentor';
CREATE DATABASE mentor OWNER mentor;
```

This matches the default `database_url` in `app/config.py` (`postgresql+psycopg://mentor:mentor@localhost:5432/mentor`). Override it via a `.env` file (see `app/config.py`) instead of editing the default for anything beyond local dev.

Apply migrations:

```bash
alembic upgrade head
```

When models in `app/models.py` change, generate a new migration with:

```bash
alembic revision --autogenerate -m "describe the change"
```

Always review autogenerated migrations before applying — autogenerate doesn't catch everything (e.g. data migrations, some constraint changes).

## Auth

Authentication is AWS Cognito (see `infra/auth/`). The backend never sees passwords — it verifies Cognito-issued access tokens (JWT, RS256) against Cognito's JWKS endpoint, and provisions a local `users` row on first sight of a given `cognito_sub` (just-in-time provisioning; email is fetched once via Cognito's `GetUser` API).

Required env vars (put in `backend/.env`, not committed — get the values from `terraform output` in `infra/auth/`):

```
COGNITO_USER_POOL_ID=...
COGNITO_APP_CLIENT_ID=...
```

Protected endpoints expect `Authorization: Bearer <access token>`. To get a test token from the CLI:

```bash
aws cognito-idp admin-create-user --user-pool-id <pool-id> --username <email> \
  --user-attributes Name=email,Value=<email> Name=email_verified,Value=true --message-action SUPPRESS
aws cognito-idp admin-set-user-password --user-pool-id <pool-id> --username <email> \
  --password '<password>' --permanent
aws cognito-idp initiate-auth --auth-flow USER_PASSWORD_AUTH --client-id <client-id> \
  --auth-parameters USERNAME=<email>,PASSWORD='<password>'
```

## Run locally

```bash
pip install -e .
uvicorn app.main:app --reload
```

Then check `http://localhost:8000/health`, or `http://localhost:8000/docs` for the interactive API docs.
